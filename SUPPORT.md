# Support

Need help with the NO! Slack app? Start here.

## Using the app

- **`/no`** shows you a random reason that only you can see. Press **Send** to post it to the
  channel, **Shuffle** for another one, or **Cancel** to dismiss it.
- **Mention `@NO`** in a channel and it replies in a thread.
- **Send it a direct message** and it replies with a reason.

## Common problems

**The bot doesn't reply to mentions in a channel.**
Invite it to that channel first: `/invite @NO`. `/no` and direct messages work without an
invite.

**I can't send the bot a direct message.**
Make sure you're messaging the app from its **Messages** tab. If the tab says sending messages
is turned off, ask a workspace admin to reinstall the app.

**Send says nothing, or the reason isn't posted.**
A `/no` preview can only be sent within 30 minutes. Run `/no` again for a fresh one.

**"/no failed with the error dispatch_failed" or a similar error.**
The app may be briefly unavailable. Try again in a minute. If it keeps happening, report it
below.

**Installing fails with "Something went wrong when authorizing".**
Start again from the install link instead of using the browser's back button:
[Add NO! to your workspace](https://no-as-a-service-slack.duckdns.org/slack/install).

## Removing the app

Go to **Tools → Apps → NO! → Configuration → Remove App**. Everything the app stored for your
workspace is deleted right away. See the [privacy policy](PRIVACY.md) for details.

## Contact

Report a bug, ask a question or request a feature by opening an issue at
[github.com/bashu/no-as-a-service-slack/issues](https://github.com/bashu/no-as-a-service-slack/issues).
Please include what you did, what you expected and what happened instead (screenshots help).
Don't include tokens or other secrets.
